# Keystone Akuru — public distribution

By Keystone Software Technologies Private Limited.

- Website: https://damithkothalawala.github.io/keystone-akuru.github.io/
- Public font database: [fonts.json](fonts.json)
- Public app update manifest: [latest.json](latest.json)
- App binaries and checksums: [Releases](https://github.com/damithkothalawala/keystone-akuru.github.io/releases)

The application source code is maintained privately. This repository contains only public distribution material.

The catalog contains 42 families / 50 font files. Files from JakeLoganUK/Sinhala-Unicode-Fonts are linked to their original, pinned upstream source. Exact embedded terms are included in the JSON: three files state personal/non-commercial use; the other 18 have no embedded license text. The application does not grant font usage or redistribution rights. Google Fonts entries retain their original SIL OFL terms.

The ICTA collection adds 15 families / 18 font files downloaded from the original ZIP archives linked at https://www.icta.lk/fonts. Archive and extracted font checksums are recorded separately. AdBhashitha and BhashitaScreen contain CC BY 4.0 embedded terms; the other 16 files contain no embedded license statement. These fonts are not bundled or mirrored.

The macOS app is universal (Apple Silicon and Intel), ad-hoc signed and not notarized. The public update manifest links to the release ZIP and records its SHA-256 and byte count. Update checks do not execute or replace the application automatically.

The sidebar includes a managed installer and updater for [Sinhala Wijesekara](https://github.com/sdasun/mac-wijesekara), created by **Dasun Sameera Weerasinghe**. The original layout, icon and MIT license are included in the application. Updates are checked against the original upstream project and applied with the user's Update button. Existing unmanaged or modified copies are left for review.
